# Pletina 0.13.0

Puedes llevar tu biblioteca a la versión web desde **Tu biblioteca → Llevar mi biblioteca a la web**. Guarda la copia e instala Pletina desde Tuqo. Abre el icono nuevo y elige el archivo en **Tu biblioteca → Copia de seguridad**. La copia se queda en tu dispositivo.

Se trasladan favoritos, listas, historial y progreso de pódcasts. La revisión de la copia indica los datos que requieren atención. Los archivos de audio descargados se conservan en la aplicación anterior mientras siga instalada. Puedes volver a descargar en la web el audio disponible. Si usas Android Auto, puedes seguir usando la APK.

La búsqueda de Android Auto consulta tu biblioteca y también el catálogo cuando no encuentra coincidencias guardadas. Los pódcasts tienen botones para retroceder y avanzar 15 segundos.

[Abrir Pletina en Tuqo](https://pletina-app.tuqo.ru/?import=native)
